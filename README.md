
# 🌦️ Week 6 – Weather Dashboard

## IYF Wecan Academy – Season 12

This is my Week 6 project. I built a responsive Weather Dashboard using HTML, CSS and JavaScript. The application uses a weather API to get and display current weather information.

## 🚀 Features

- Search for weather by city.
- Display current temperature.
- Show weather conditions.
- Display humidity and wind speed.
- Responsive design for mobile and desktop.
- Fetch live weather information from an API.
- Secure backend API integration.
